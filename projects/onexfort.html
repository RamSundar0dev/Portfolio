Onexfort

A field-service SaaS platform bringing CRM, job management, scheduling, quoting and invoicing into one system for removalists, cleaners and electricians.

Visit onexfort.com ↗

Overview

Onexfort is a software-as-a-service platform for field-service businesses. It replaces the spreadsheets and disconnected tools these teams usually rely on with one place to manage customers, schedule jobs, send quotes and raise invoices — on both web and mobile.

I work on Onexfort as part of the core team, building features across the stack and helping shape the architecture as the product scales across more customers and industries.

What I did

  • Designed and built web and mobile features using React, React Native, Laravel and MySQL.
  • Used AWS S3 for scalable data and document storage across the platform.
  • Built reporting and analytics with AWS QuickSight so customers get actionable insight from their data.
  • Contributed to architecture decisions, code review and delivery as part of the senior team.
