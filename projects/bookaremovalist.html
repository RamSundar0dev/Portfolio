Visit bookaremovalist.com.au ↗

Overview

BookaRemovalist is an online marketplace for the Australian moving industry. It doesn't move anything itself — instead it helps customers quickly get, compare and book quotes from multiple vetted removal companies in one place.

I built the web application and the flows that make comparing and booking removalists fast and trustworthy.

What I did

  • Built the marketplace web application with React.js, Laravel and PostgreSQL.
  • Implemented the quote, comparison and booking flows that connect customers with removalists.
  • Worked with a PostgreSQL data model designed for matching customers to the right providers.
