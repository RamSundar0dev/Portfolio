Overview

GetRostered helps businesses manage their workforce in real time — handling scheduling, talent management and the day-to-day coordination a growing team needs.

I built scalable web and mobile applications for the product and integrated the AWS services that keep it secure and insightful.

What I did

  • Built scalable web and mobile apps with React, React Native, Laravel and MySQL.
  • Integrated AWS Cognito for authentication and secure user access.
  • Stored user-generated content on AWS S3 and surfaced insights through QuickSight reporting.
